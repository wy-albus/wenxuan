# 文轩销量预测正式评价口径

## 训练阶段选模

模型轮次和候选组合统一使用 **Complete Valid Overall WAPE** 选择：

`sum(abs(y_true - y_pred)) / sum(y_true)`

指标在原始非负销量尺度计算。使用对数目标的模型必须先执行反变换并截断为非负值。该口径与现有 Active-Store LightGBM 实验一致，便于不同模型公平选轮。Test 不参与轮次、参数、组合或阈值选择。

## 最终业务评价

**Nonzero WAPE** 是主要销量指标，只在真实销量大于 0 的样本上计算，用于回答实际发生销售时预测是否准确。

`5 <= qty < 20` 和 `qty >= 20` 单独评价。这两组代表中高销量和头部需求，不能被占比很高的零销量样本掩盖。

真实销量为 0 的样本不进入 Nonzero WAPE，因为其真实销量总和为 0，WAPE 没有有效分母。零销量风险仍独立报告：样本量、平均预测、预测总量、预测大于 0.5 的比例和预测大于 1 的比例，用于控制无销量商品的误报和虚假补货需求。

Overall WAPE、MAE、RMSE 和 Total Bias 作为全局辅助指标。它们用于观察单条误差、极端误差和集团总量偏差，但不单独决定业务优劣。

## 业务任务含义

- **销量回归**：回答未来 1M 或连续 2M 的销量本数。
- **MC 动销等级**：将回归销量按项目当前五级规则映射，回答商品处于哪一档动销水平。2M 使用两个月累计销量的月均值。
- **趋势**：比较当前月销量与未来销量方向。1M 使用未来单月，2M 使用未来两个月月均；大于为上升，小于为下降，完全相等为持平，不另设未经确认的百分比阈值。
- **总量**：比较真实销量总和、预测销量总和和 Total Bias，回答集团整体需求规模是否被系统性高估或低估。

当前 MC 五级边界属于项目已使用的暂定口径，配置位于 `config/mc_sales_levels.yaml`。后续业务边界变化时只修改统一配置，不在训练或评价脚本中硬编码。
