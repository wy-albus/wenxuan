## 业务结论

- **1m**：MLP test MAE 相对加权移动平均改善 31.78%，但比 LightGBM V2 高 2.64%；相对随机森林改善 7.46%。总量偏差为 -32.99%，仍存在明显低估。
  nonzero/5-20/20+ WAPE 为 78.98% / 73.33% / 88.99%，均未超过 LightGBM V2；说明 MLP 的整体收益仍有相当部分来自零销量样本。
  零销量平均预测 0.0436，预测 >0.5 / >1 的比例为 0.90% / 0.26%，误报总体可控。
- **2m**：MLP test MAE 相对加权移动平均改善 35.44%，但比 LightGBM V2 高 6.27%；相对随机森林改善 0.59%。总量偏差为 -30.41%，仍存在明显低估。
  nonzero/5-20/20+ WAPE 为 76.05% / 70.48% / 86.23%，均未超过 LightGBM V2；说明 MLP 的整体收益仍有相当部分来自零销量样本。
  零销量平均预测 0.0773，预测 >0.5 / >1 的比例为 1.96% / 0.54%，误报总体可控。
- 两个 horizon 的训练损失持续下降，而 early-valid 在最佳轮次后进入波动并触发早停，存在轻微过拟合倾向，但已由最佳 checkpoint 恢复机制控制。
- MLP 可保留为神经网络结构对照，但当前不应替代 LightGBM V2 作为默认补货点预测模型；随机森林在 nonzero 上也更稳健。
